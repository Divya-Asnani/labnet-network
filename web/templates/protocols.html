TCP Broadcast Chat
TCP :5001

Purpose: Reliable, ordered, connection-oriented real-time messaging across lab workstations.

How it works: Uses AF_INET / SOCK_STREAM with one worker thread per client and newline-delimited JSON framing to maintain message boundaries over a continuous TCP byte stream. Supabase stores message history separately for offline retrieval.

Implementation: server/tcp_chat_server.py & clients/tcp_chat_client.py

Chunked TCP File Transfer
TCP :2121

Purpose: High-throughput, reliable binary file upload with cryptographic integrity checks.

How it works: Exchanges a JSON metadata handshake (filename, filesize, sha256), waits for READY ACK, streams 64 KB binary chunks, computes SHA-256 in flight, and writes to uploads/.

Implementation: server/tcp_file_server.py & clients/tcp_file_client.py

Reliable UDP (Sliding-Window ARQ)
UDP :2122

Purpose: Demonstrates building reliability, sequencing, and loss recovery atop connectionless UDP datagrams.

How it works: Splits files into 1024-byte sequenced datagrams, transmits up to WINDOW_SIZE=5 in-flight chunks, handles selective ACKs, detects duplicates/out-of-order arrivals, retransmits on timeout, and verifies SHA-256 after reassembly.

Test CLI: python clients/udp_file_client.py file.bin --server {{ server_ip }} --loss-rate 0.20

Direct Peer-to-Peer Transfer
TCP :2123

Purpose: Workstation-to-workstation file transfer without relaying file contents through VM1.

How it works: Receiving peer registers its reachable IP & port via /api/peers/register. Sender connects directly to the peer's socket; VM1 coordinates discovery & metadata only.

Test CLI: python clients/p2p_node.py --listen --port 2123

UDP Heartbeat & Presence
UDP :6000

Purpose: Low-overhead liveness monitoring and automatic offline timeout detection.

How it works: Clients emit periodic HEARTBEAT|id|ts datagrams and receive HEARTBEAT_ACK. Missing heartbeats past HEARTBEAT_TIMEOUT mark the device offline in Supabase.

Test CLI: python clients/heartbeat_client.py --server {{ server_ip }} --simulate-missed 4
